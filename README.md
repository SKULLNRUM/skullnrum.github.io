# SKULLNRUM

An independent artist world — an atmospheric, artwork-led archive and community.

## Build direction

- Dark, raw, eerie, esoteric pirate / underground identity.
- Distinct desktop and mobile compositions, not just a scaled-down desktop layout.
- Hidden details, easter eggs, unlockable content, and a community that does not feel like a generic social network.
- Search-discoverable metadata and share previews.

## Sections

1. **The Departure** — black opening, the exact original bird carrying the skull and rum bottle artwork, and the Sun Jolly Roger. The bird recedes diagonally and shrinks with scroll to create a flight/perspective illusion.
2. **The Wake** — skull jaw opens, rum bottle reveal, negative-space ocean waves and a ship.
3. **The Crew / Artist** — artist identity, accounts and usernames, comments, and live community interaction.
4. **Restricted** — a gated room for unreleased music.

Admin tools will eventually support moderation and site management. Authentication, data, and permissions can be added as a later backend phase.

## Current build

Section 01 is the first implementation in `index.html`.

The original artwork must be supplied unchanged at these paths:
- `assets/bird-skull-rum.png`
- `assets/sun-jolly-roger.png`

Do not substitute, redraw, or generate replacement artwork. Once the exact originals are added, the scroll-driven perspective animation is wired up.

Build one section at a time and preserve the direction above as the site grows.
